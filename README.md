# meishe-android-streaming-sdk-skill

> Modular AV creation skills for Android—capture, edit, effects, and stream with composable SDK components.

## Overview

Meishe Android Streaming SDK Skill packages production-grade audio/video capabilities into modular skills for Android apps. Instead of building a full AV pipeline from scratch, teams can integrate only the modules they need and ship video creation, live streaming, and AI-assisted editing experiences faster.

## Key Skills

- **Capture & Preview** — camera/media input and real-time preview
- **Timeline Editing** — NLE-style timeline, tracks, clips, and trimming
- **Real-time Effects** — filters, stickers, and visual packaging
- **AI-assisted Creation** — smart editing and highlight discovery
- **Output & Streaming** — recording, export, and streaming-ready pipelines

## Why This Skill

- Composable modules for lean integration
- Production-grade AV architecture
- Designed for Android app developers
- Faster time-to-market for video and live features

## Typical Use Cases

Short video apps · live commerce · social streaming · video editing tools · enterprise media apps

## Getting Started

1. Review the integration guide and sample project.
2. Select the skill modules required by your app.
3. Add the SDK dependency and configure capture/editing/export.
4. Test on target Android devices and ship.

> Dependency coordinates, sample code, and SDK references: see the repository docs.
