# Resource Requirements Index

Use this file when a user asks for an Android Streaming SDK feature or a complete app. It maps demo-derived feature modules to the runtime resources that must be supplied by the customer or copied from an approved SDK/demo asset source.

The original `SdkDemo` folder is not required when using this skill. Demo asset family names below are provenance labels only, extracted from the demo's `app/src/main/assets` layout so the skill can ask for the right kind of files.

## Usage Rule

1. Always include `R0 core-runtime` for generated apps or patches that call `NvsStreamingContext`, `NvsEffectSdkContext`, or `NvsAssetPackageManager`.
2. Before implementing a feature that needs media, SDK packages, models, fonts, template data, or output paths, list the matching `R*` rows to the user as required inputs.
3. Do not block implementation on optional resources. Generate hooks, placeholders, and clear file placement paths, then state which resources are still needed for runtime behavior.
4. Do not require package assets for built-in-only effects. Built-in FX can be generated with only `R0 core-runtime`; packaged filters, transitions, stickers, captions, AR props, themes, and templates require package rows.
5. The skill stores no material binaries. Before a first-run offline demo that needs materials, tell the user to contact Meishe business, then use an authorized external lightweight bundle when sufficient; it does not replace production-authorized packages or the full model directory from the official Android LTS face package.
6. Resolve runtime libraries, optional helper libraries, human-detection models, and Demo material families from `official-sdk-download-resource-map.json`. Tell the user to download Android LTS with `下载SDK人脸版本` from `https://www.meishesdk.com/downloads`, then use package-relative paths only.
7. If a resource family is not present in demo-derived references or official docs, ignore it for now.
8. Do not request or generate material-service addresses, catalog schemas, authentication, or download contracts. If the user asks about online material interfaces, tell them to contact Meishe business.
9. If a mapped runtime, model, or Demo material file is unavailable, report its exact `<sdk-root>`-relative source and project destination and keep dependent controls disabled. For online material interfaces, production package acquisition, or production application/package `.lic` files, direct the user to Meishe business.

## Feature To Resource Map

| User-facing feature | Resource keys to list | Notes |
| --- | --- | --- |
| Minimal edit app, clip join, trim, split, timeline project | `R0`, `R1`, `R3` | Add `R7` only when music/voice is requested. |
| Complete short-video editor with media picker, live preview, child modules, and export | `R0`, `R1`, `R3`, plus requested child-feature rows | Add `R4`/`R5` for packaged filters/transitions, `R6` for captions/stickers/fonts, `R7` for music/voiceover, and `R8` for beauty/makeup/AR. An authorized external local bundle can cover first-run examples. |
| Camera preview or simple recording | `R0`, `R2` | Add `R5` for capture filters, `R8` for beauty/AR. |
| Preview, seek, scrub, playback controller | `R0`, `R3` | For caption/sticker poster seek flags, also list `R6` when those overlays are requested. |
| Export/compile/share rendered video | `R0`, `R3`, `R1` | Output path can be app-specific until MediaStore/share flow is added. |
| Built-in filter, Transform 2D, color adjust, crop, speed | `R0`, `R3`, `R5` | State clearly when no packaged FX is needed. |
| Packaged filter, transition, particle, PIP, watermark FX | `R0`, `R4`, `R5` | Ask for package files/licenses and desired package ids. |
| First-run offline demo with bundled small assets | `R0`, `R4`, `R5`, `R6`, `R7`, `R11` | Use `default-sample-assets.md`; still needs SDK runtime and valid license. |
| Online material center / downloadable package library | `R13` | Do not generate an endpoint or request client. Tell the customer to contact Meishe business for the authorized interface and acquisition process. |
| Text captions, rich captions, compound captions | `R0`, `R4`, `R6` | Ask for font files if custom typeface is part of the requirement. |
| Animated stickers or custom sticker overlay | `R0`, `R4`, `R6` | Custom sticker workflows may need sticker image/sequence assets. |
| Music, voiceover, lyrics | `R0`, `R1`, `R7` | Add `R6` for lyric captions or music-caption styles. |
| Beauty, makeup, face shape, face mesh | `R0`, `R2` or `R1`, `R4`, `R8` | Capture mode uses `R2`; edit mode uses `R1` timeline media. |
| AR scene / props | `R0`, `R2`, `R4`, `R8` | Check `NvsStreamingContext.hasARModule()` before enabling AR UI. |
| Segmentation, virtual background, master keyer, AI face/superzoom | `R0`, `R1`, `R4`, `R8`, `R9` | Capture-mode segmentation also needs `R2`; select required model files from the official face package's `samples/android/SdkDemo/app/src/main/assets/facemode`. |
| Mimo, CutSame, template replacement | `R0`, `R1`, `R3`, `R4`, `R10` | Standard/CutSame require a filename-preserved `.template`, optional `.lic`, descriptor-ordered media, and reverse cache only for `needReverse` slots. Mimo requires its ZIP/`info.json`, child packages/music, and ordered shot media. If these files are unavailable, add `R13` and refer acquisition to Meishe business. |
| Themes, albums, PIP, watermark | `R0`, `R1`, `R4`, `R11` | Some theme flows also use `R7` music and `R6` captions/stickers. |
| Media conversion, frame extraction, thumbnails | `R0`, `R1`, `R12` | Does not require UI unless user wants a visible workflow. |

## Ask-User Output Template

When the user requests a feature, include a compact resource request before or alongside implementation details:

```text
这个功能需要这些资源：
- 必需：<R0/R*/placement paths>
- 官网总包来源：<sdk-root-relative source path; Android LTS 下载SDK人脸版本>
- 取决于你选择的效果包：<optional package/model/font/media items>
- 放置建议：<app/src/main/assets, app/libs, app/src/main/jniLibs/arm64-v8a, app-specific media/output>
我会先生成可运行骨架和资源占位；缺少以上资源时，相关 SDK 调用会保留保护判断或返回失败。
```

Keep this as a resource checklist, not a requirement to copy the full Demo. Copy only selected package-relative files or accept equivalent authorized resources.
