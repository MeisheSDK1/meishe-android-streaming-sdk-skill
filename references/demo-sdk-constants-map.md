## Constant Selection Rules

- Use `NvsStreamingContext.STREAMING_ENGINE_STATE_*` only for engine-state comparisons; do not pass state constants as capture/record flags.
- Combine `NvsStreamingContext.STREAMING_ENGINE_CAPTURE_FLAG_*` with bitwise OR for capture preview options.
- Use `NvsStreamingContext.STREAMING_ENGINE_RECORDING_FLAG_*` for recording stop/recording behavior, not compile/export.
- Use `NvsStreamingContext.COMPILE_*` constants only in `compileTimeline` configuration positions.
- Use `NvsAssetPackageManager.ASSET_PACKAGE_TYPE_*` according to the package domain: video FX, theme, transition, caption, animated sticker, AR scene, capture scene, face mesh, warp, makeup, template.
- Use `NvsAssetPackageManager.ASSET_PACKAGE_STATUS_*` for status checks before install/update.
- Use `NvsAssetPackageManager.ASSET_PACKAGE_MANAGER_ERROR_*` for install/update callback or return-code handling.
- Use `NvsExpressionParam.TYPE_*` to choose `setColorVal`, `setFloatVal`, `setIntVal`, `setBooleanVal`, or `setStringVal`.
- Use template aspect-ratio and footage-type constants only for CutSame/Mimo/template material validation.
